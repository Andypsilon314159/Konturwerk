# Konturwerk

Eine kleine, lokale Browser-Anwendung, die Rastergrafiken in SVG-Konturen umwandelt.

## Starten

Es sind keine Abhängigkeiten und keine Installation erforderlich. Öffne einfach
[`index.html`](index.html) in einem aktuellen Browser.

## Funktionen

- Import von PNG, JPG, WebP und GIF
- Schwarzweiß-Vektorisierung mit einstellbarem Schwellwert
- Farbreduzierung mit 2 bis 12 getrennten SVG-Ebenen
- Einstellbarer Detailgrad, um Dateigröße und Detailtreue auszubalancieren
- SVG-Export; die Datei lässt sich beispielsweise mit Figma, Illustrator oder
  Inkscape weiterbearbeiten

Die Bildverarbeitung bleibt vollständig im Browser; es gibt keinen Server-Upload.
